`I003`의 폐지·정리매매 후보 3,487건, `I001`의 국내 폐지 언급 1,095건, `E003`의 합병·포괄적 주식교환/이전 종료보고서 1,088건을 골라 API 원문 수집을 마쳤다. 5,670건 중 종목코드가 없는 10건은 별도 보존하고, 5,660건을 요청했다. 결과는 새 다운로드 4,997건, 기존 원문 재사용 554건, API 제공 불가 109건이며 수집 오류는 0건이다. 확보한 5,551건은 본문·압축 원본 해시와 접수번호·종목코드가 모두 일치했다. 종목코드나 실제 폐지 여부를 임의로 만들어 넣지 않는다. 035480의 경우 최초 공시는 2019-10-17 폐지를 예정했고, 2019-10-04 정정에서는 감자주권 변경상장 일정을 이유로 폐지 예정일을 10월 31일로 바꿨다. 이후 절차가 보류됐고, 2019-11-29 공시는 12월 정리매매 재개와 2019-12-12 폐지 일정을 명시한다. 2020-03-30 제출 사업보고서에는 실제 2019-12-12 최종 상장폐지가 기록돼 있다. 마지막 원시 가격일은 2019-12-11이다. 공식 원문 6건의 해시와 정확한 문구를 [개별 증거 기록](../../deliverables/cross_market_top70_20260909/survivorship/KR_035480_delisting_evidence.json)에 보관했다. 중간 정정 원문은 OpenDART API에서는 제공 불가였지만 DART 공개 웹사이트의 본문을 별도로 확보했다. 기존 API 제공 불가 기록과 복구 전 증거 파일도 보존했다.

해당 사업보고서는 XML 선언이 UTF-8이지만 실제 바이트는 EUC-KR로 엄격 디코딩해야 문구가 확인됐다. 연구 증거에 적용한 인코딩을 기록했으며, 공통 파서나 원본 파일을 변경하지 않았다. 상장폐지 사실은 주식 소각이나 최종 자산가치 0을 뜻하지 않으므로, 여기서 확인하지 않은 청산대가·장외 실현가격을 임의로 수익에 넣지 않는다.

API 제공 불가 109건을 DART 공개 웹사이트에서 추가 확보하는 작업은 반복적인 연결 끊김으로 중단했다. 공개 공시 메인 32개와 본문 범위 100개가 저장됐으며, 전부 원문 및 참조 메인 페이지의 해시가 일치했다. 마지막 실행 기록에는 60건의 처리 결과, 표시된 본문 범위를 모두 확보한 28건, 오류 또는 일부 범위 누락 32건이 남아 있다. 별도로 미리 확보한 035480 본문도 보존돼 있다. 전체 109건의 공개 본문을 모두 확보했다고 간주하지 않는다.
