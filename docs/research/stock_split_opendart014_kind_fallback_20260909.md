# OpenDART 원문 014의 공식 KIND 대체 경로

- 확인일: 2026-09-09~10 (한국시간; 파일명의 날짜는 조사 시작일)
- 범위: OpenDART 목록에는 있으나 `document.xml`이 `014`를 반환한 공시의 대체 원문, 주식분할·병합의 실제 적용일과 비율. DART 공개 사이트 재시도, 차단 우회, IP/Host 변경, 코어 코드·DB 변경은 하지 않았다. 인증키도 사용하거나 저장하지 않았다.
- 결과: **KIND의 정상 상세검색 → 공시뷰어 → 본문 경로가 작동했고, 삼성전자 분할과 캔버스엔 병합의 원문 및 실제 시장조치를 내려받았다.** 공식 사이트의 공개 조회·다운로드 기능을 확인한 것이며, 문서화된 범용 JSON 기업행사 API를 발견했다는 뜻은 아니다.

## OpenDART 014의 의미와 대체 범위

OpenDART는 `document.xml` 정상 결과를 ZIP 바이너리로 설명하고 `014`를 파일 부재로 정의한다. 확인한 개발가이드는 014에 대한 별도 원문 API, 자동 KIND 변환 인자, 재시도 후 복구 보장을 제공하지 않는다. 따라서 014를 빈 정상 문서로 저장하거나 전체 공시가 없었다고 취급하지 않는다. 공식 원문을 다른 경로에서 얻었더라도 `opendart_document_status=014`와 대체 출처는 따로 보존한다. [OpenDART 공시서류원본파일 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003).

현재 직접 검증한 대체 경로는 거래소가 운영하는 KIND의 공개 공시 본문이다. 같은 회사·접수일·보고서명·정정 정보를 검색해 연결한다. **DART 접수번호와 KIND 접수번호·문서번호는 별개의 식별자**다. 숫자의 일부를 바꾸어 일반 변환 규칙을 만들지 않는다. 단일 표본에서 정정 본문을 확보한 사실이 모든 DART 첨부정정 원문도 KIND에 존재함을 증명하지는 않는다. 첨부는 뷰어의 첨부 선택 항목과 실제 파일을 별도로 확인해야 한다. [KIND 상세검색](https://kind.krx.co.kr/disclosure/details.do?method=searchDetailsMain).

## 실제 작동한 공식 사이트 경로

아래 인자와 함수명은 내려받은 KIND 공식 HTML/JavaScript에서 확인하고 정상 요청으로 실행했다. 사이트 UI 계약이므로 운영 시 응답 구조·페이지 수·HTTP 상태를 검증해야 한다.

| 단계 | 요청 | 확인한 응답 |
| --- | --- | --- |
| 검색 화면 | `GET https://kind.krx.co.kr/disclosure/details.do?method=searchDetailsMain` | 검색 폼, `주식분할/병합` 유형, EXCEL 버튼 |
| 검색 결과 | 같은 호스트 `/disclosure/details.do`에 POST. `method=searchDetailsSub`, `forward=details_sub`, `fromDate/toDate`, `reportNm`, `pageIndex=1`, `currentPageSize=100` | 회사, 공시명, 접수시각, `openDisclsViewer(acptno,docno)` 링크 |
| 검색 목록 EXCEL | 같은 검색 조건에서 `forward=details_down` | 다운로드 파일; 이번 표본은 **EUC-KR HTML 형식의 `.xls`** |
| 공시뷰어 | `GET /common/disclsviewer.do?method=search&acptno=...&docno=` | 회사·종목코드, 원문/정정/첨부 선택 목록 |
| 본문 위치 | `GET /common/disclsviewer.do?method=searchContents&docNo=...` | `parent.setPath(...)`의 공식 본문 URL |
| 원문 다운로드 | 응답에 실제로 제시된 `https://kind.krx.co.kr/external/.../*.htm` | 분할·병합 표, 변경상장·정지해제 원문 |

정확한 POST 인자는 표본 디렉터리의 `kind_samsung_amendment_search_request.json`과 manifest에 있다. 회사명을 비운 단기 검색도 작동했다. 분할·병합 후보는 `reportNm=주식분할` 또는 `주식병합`, 실제 시장조치는 `변경상장` 또는 `주권매매거래정지해제`로 발견했다. 검색 결과의 기업 링크 `companysummary_open('00593')`는 KIND 내부 식별값이므로 6자리 종목코드로 바로 쓰지 않는다. [공식 검색화면](https://kind.krx.co.kr/disclosure/details.do?method=searchDetailsMain), [공식 뷰어 호출 스크립트](https://kind.krx.co.kr/js/JCommon.js?version=20260417).

원문 선택 시 `mainDoc` 옵션의 `docNo|Y/N`을 보존한다. 과거 정정의 원문을 찾는 작업에서는 검색한 공시 날짜·제목과 일치하는 옵션을 선택하고, 단순히 최신 옵션으로 덮어쓰지 않는다. 실제 최종 시행 사건을 만들 때는 전체 정정 계보와 후속 시장조치를 함께 해석한다. `.htm` 경로의 날짜·번호는 사전에 조합하지 않고 `searchContents` 응답에서 얻는다.

검색화면 JavaScript는 조회기간을 최대 3년으로 제한하고 1년 초과 구간에는 추가 검색 조건을 요구한다. 이번 검증은 1일 또는 8일 범위였다. 2018-04-27~05-04 `변경상장` 검색에는 ETF를 포함해 총 199건/2페이지가 있었으며, 필요한 삼성전자 공시는 첫 페이지에서 확인했다. **이 연구는 전체 199건을 수집한 결과가 아니다.** 운영 수집은 조건을 좁히거나 모든 페이지 완료 여부를 기록해야 한다. [KIND 상세검색 화면의 공식 폼·함수](https://kind.krx.co.kr/disclosure/details.do?method=searchDetailsMain).

## KRX가 별도 구조화 자료를 제공하는지

1. **즉시 검증한 무료 공개 경로는 KIND 공시 목록 EXCEL과 개별 공식 본문이다.** 본문에서 분할·병합 비율과 실제 변경상장일을 추출할 수 있다. 목록 EXCEL 자체가 모든 종목의 확정 기업행사 비율·적용일 표는 아니다.
2. KRX 정보데이터시스템에 수정주가를 적용하는 통계 화면은 실제 존재한다. 공식 설명은 권리락·액면분할 등에 따라 과거 가격을 소급 조정한다고 밝힌다. 이것은 조정 정의의 근거이며, 이번 조사에서 모든 분할 사건을 다운로드하는 무료 API를 확인한 것은 아니다. [KRX 공모가대비 등락률 및 수정주가 설명](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT202.jsp).
3. KRX는 **지수조치정보 파일(Corporate Action)**을 포함한 지수정보상품을 공식 안내한다. 지수채용주식수 증감과 구성종목 변경 등을 포함하고 별도 문의·구독 경로가 있다. 다만 이것이 전 상장종목의 모든 과거 분할/병합 비율을 제공하는 무료 파일이라고 볼 근거는 없다. 범위·필드·과거기간은 계약 전 확인이 필요하다. 이번 작업에서 구매·신청·문의 전송은 하지 않았다. [KRX 지수정보상품](https://www.krx.co.kr/contents/GLB/05/0508/0508040100/GLB0508040100.jsp), [공식 데이터상품 안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA005.jsp).
4. 이 실행 환경에서 KRX `data` 및 `openapi` 첫 페이지의 일반 HTTP 요청은 403이었다. 추가 경로로 차단을 피하려 하지 않았고, 공개 검색으로 확인되는 공식 설명을 읽는 수준에서 조사했다. 따라서 **공개 분할·병합 전용 API의 부재를 단정하지 않으며, 이번 조사에서 문서화된 무료 전용 API는 확인하지 못했다**고 기록한다.

## Arcana에 적용할 운영 제안

`OpenDART 목록 + document.xml 성공 원문`을 유지하고 014의 거래소공시는 KIND 대체 수집 후보로 분리한다. 회사·공시일·정규화한 제목으로 후보를 찾되 본문 내용과 정정 계보를 확인한 후 연결한다. `source_provider`, `dart_rcept_no`, `kind_acpt_no`, `kind_doc_no`, 원문 URL·해시·인코딩, 연결 근거와 상태를 저장한다. KIND HTML을 OpenDART ZIP으로 가장하거나 원래 014 기록을 지우지 않는다.

실제 조정 사건은 거래소 변경상장/정지해제 본문을 우선 증거로 삼는다. 확정 비율·증권·날짜가 없으면 검토 대기 상태를 유지한다. 중복 원문 경로에서 같은 사건을 두 번 곱하지 않는다. 가격 조정 수식과 날짜의 경제적 의미는 [앞선 DART 계약 문서](stock_split_dart_source_contract_20260909.md)를 따른다.

## 저장한 증거

표본 디렉터리: [stock_split_official_fallback_samples_20260909](stock_split_official_fallback_samples_20260909/).

- `kind_sample_manifest.json`: 신규 원문·검색·뷰어·contents 응답·EXCEL의 정확 URL, 요청, 인코딩, SHA256.
- `kind_samsung_amendment_*_request.json`: 처음 검증한 검색·뷰어·contents 요청의 추가 출처 정보.
- `kind_details_search_main.html`: 공식 검색 폼, 조회 제한, EXCEL 다운로드 함수를 확인한 HTML.
- `kind_expected_events.json`: 위 표본에서 수동 확인한 비율·증권·적용일과 출처 연결값.
- `kind_sample_validation.json`: 원본 응답 18개 SHA256 검증과 과거 DART 표본 대조. 삼성 정정, 캔버스엔 정정, 캔버스엔 거래정지해제의 표 텍스트는 공백 정규화 후 DART/KIND가 모두 동일했다.

샘플 요청은 단기간·소수 공시에 한정했으며 전체 시장의 수집 완료율, 모든 014의 복원 가능성, 모든 기업행사의 포괄성을 검증한 결과는 아니다.
